# Student Management System

This is a PHP/MySQL project for managing students, courses, instructors, classrooms, and enrollments.

## Setup
1. Upload the project to a web server (XAMPP, WAMP, InfinityFree).
2. Run `school_db.sql` to create the database and sample data.
3. Update `db.php` with your MySQL credentials.
4. Access the pages:
   - `students.php`
   - `create_instructor.php`
   - `classroom.php`
   - `courses.php`
   - `update_course.php`
   - `enrolled.php`

## Features
- View, create, and update records
- HTML, CSS, JavaScript, PHP, MySQL used
