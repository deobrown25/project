---

## Local Version (XAMPP/WAMP)

To run the project locally:  

1. Install XAMPP (or WAMP/LAMP) on your computer.  
2. Place the `project` folder inside the `htdocs` directory.  
3. Open phpMyAdmin (http://localhost/phpmyadmin) and import `school_db.sql` to create the database and data.  
4. Update `db.php` with your local database credentials.  
5. Open a browser and go to: http://localhost/project/students.php
6. Navigate to other pages as needed.
